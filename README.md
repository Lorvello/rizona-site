# rizonastudio.com

De website van Rizona Studio. Deze tak (`gh-pages`) staat live via GitHub Pages: een push is binnen een paar minuten online.

- Overdracht, keuzes achter het ontwerp en een controlescript staan op de tak [`overdracht`](https://github.com/Lorvello/rizona-site/tree/overdracht).
- Laat `CNAME`, `.nojekyll` en `privacy/` altijd staan. De LinkedIn-apps linken naar `/privacy/`.
